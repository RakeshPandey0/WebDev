## JavaScript Core Concepts & Advanced Topics

The `javascript/` directory is a deep dive into the JavaScript language, structured into multiple parts to facilitate progressive learning.

### Part 1: Basics & Functions

1. `variables_data_types.js`: Understanding JavaScript variables and different data types.
2. `operators.js`: Working with various JavaScript operators.
3. `type_conversion.js`: Exploring explicit and implicit type conversions.
4. `control_statements.js`: Implementing conditional logic and loops.
5. `functions.js`: Defining and using functions, including parameters and return values.
6. `object.js`: Introduction to JavaScript objects and their manipulation.
7. `exercise.js`: Practical exercises to reinforce basic concepts.
8. `exercise_ATM.js`: A more complex exercise simulating an ATM.
9. `higher_order_function.js`: Learning about functions that operate on other functions.
10. `index.html`: Accompanying HTML file for running these scripts.

### Part 2: Classes & Prototypes

1. `Class_and_prototype.js`: Understanding ES6 Classes and the underlying prototype-based inheritance.
2. `Class_exercise.js`: Exercises focused on class creation and usage.
3. `Class_concepts.js`: Further exploration of advanced class features.
4. `Getters_Setters.js`: Implementing getters and setters in classes for controlled property access.
5. `Part_2_exercise.js`: Additional exercises for this section.
6. `index.html`: Accompanying HTML file.

### Part 3: Asynchronous JavaScript (Promises, Async/Await)

1. `Promise.js`: Deep dive into Promises for handling asynchronous operations.
2. `PromiseExercise.js`: Practical exercises on Promises.
3. `Async_Await.js`: Mastering async/await for cleaner asynchronous code.
4. `Async_Await_Exercise.js`: Exercises applying async/await.
5. `Async_Await_Exercise2.js`: Further complex exercises for asynchronous patterns.
6. `index.html`: Accompanying HTML file.

### Part 4: Document Object Model (DOM) Manipulation

1. `DOM.js`: Introduction to the Document Object Model.
2. `DOM_creating_inserting_elements.js`: Learning to dynamically create and manipulate HTML elements.
3. `DOM_exercise_todo.js`: A practical Todo List application built using DOM manipulation.
4. `index.html`, `style.css`, `Todo.css`, `todoDOM.html`: Files related to DOM exercises.

### Clone the Repository:

```bash
git clone https://github.com/RakeshPandey0/WebDev.git
cd WebDev
```

**Install Dependencies (for Node.js/React projects):**
For projects using Node.js (like Express, Node Discord Bot, React projects), navigate into the specific project directory and install dependencies:

```bash
npm install
# or
yarn install
```

**Run Projects:**
Refer to the scripts in package.json within individual project folders for specific run commands (e.g., npm start, node index.js).
